## About

Website for Baker House at MIT. Maintained by Baker House WebMaster.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:4321](http://localhost:4321) to preview locally.

## Deployment

Push to the `main` branch on GitHub. GitHub Actions builds the Astro site and publishes `dist/` to GitHub Pages (custom domain: baker.mit.edu).

```bash
npm run build   # static output in dist/ (includes Pagefind search index)
```
