## About
This is the website of the best MIT dorm, Baker House, Baker Home! Site created and maintained by Baker House WebMaster.

## Getting Started

This repo is currently configured to output a static site to the /out folder.

Run 

```yarn build```

to create the static site files and 

```npx serve@latest out```

to serve to local.


Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

To make changes to the dorm site, commit and push to GitHub. The site will updates within a few minutes.
